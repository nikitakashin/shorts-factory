# Правила SEO-упаковки: лимиты, правила проекта, что говорят источники

Колонка «Надёжность»: **док** — документация YouTube/Google; **проект** — решение автора канала; **обзор** — блоги и посты без первоисточников
(использовать как подсказку, не как закон); **данные** — проверяет `validate.py`.

## 1. Лимиты (валидатор проверяет)

| Что | Лимит | Надёжность |
|---|---|---|
| Название | ≤ 100 символов | док |
| Описание | ≤ 5000 байт (кириллица — 2 байта на символ) | док (API) |
| Теги | ≤ 500 символов суммарно; тег с пробелом считается с кавычками | док |
| Хештеги | > 15 в названии и описании вместе — YouTube игнорирует все. Первые 3 из описания показываются над названием | док |
| Хештег | слитно, с `#`, без пробелов и знаков | док |
| Теги | YouTube сам пишет, что они мало влияют на поиск; нужны для вариантов написания | док / обзор |

## 2. Правила проекта (из adhd-shorts/references/package.md)

| Правило | Надёжность |
|---|---|
| Название ≤ 100 символов **вместе с хештегами** (автор, 2026-10-17); смысл и главный ключ — в первых ~40 символах (видно в ленте) | проект |
| 2–3 хештега в конце названия, `#shorts` — только в описании | проект |
| Название длинного видео ≤ 60 символов (источник B) — противоречит правилу автора, не применяем | обзор |
| Интрига без кликбейта: развязка совпадает с обещанием | проект, подтверждают A, B, C, D |
| Капс ≤ 1 слова, эмодзи 0–1 | проект |
| Не повторять название в первой строке описания слово в слово | проект |
| Факты (версии, даты, цены) — только из расшифровки и кадров | проект, подтверждает A |
| Под описанием строка хештегов: `#shorts` + тематические; всего в названии и описании ≤ 15 | проект / док |
| Хештеги TikTok/Reels не пишем: публикуем только на YouTube | проект |
| Закреп — вопрос, провоцирующий ответы | проект |

## 3. Что говорят источники (где сходятся, там правило надёжнее)

| Тема | Что сказано | Кто | Надёжность |
|---|---|---|---|
| Ключ в начале названия | Основной ключ и важные слова в первых словах | A, B, C, D | обзор, сходятся |
| Поисковый и интригующий вариант | Два типа: поисковый (ясно называет тему) и интригующий (для ленты) | A | обзор |
| Подсказки автодополнения | Вводить ключ в поиск YouTube, брать подсказки и вставлять в название | D, A, B | обзор, сходятся |
| Описание | Первые строки — сниппет, ключ и суть там; связный текст, не набор ключей; 150–300 слов для длинного | A, B, D | обзор |
| Описание: структура | Для кого → результат → ≤ 3 пункта → ссылки → главы | A | обзор |
| Главы | Первая глава `0:00`, описательные названия, таймкоды только после финального монтажа, не выдумывать | A, B | обзор |
| Теги | Мало значат; помогают с вариантами написания; общие + специфичные; только релевантные | A, B, D, док | сходятся |
| Хештеги | Источники молчат; правила — только в документации YouTube | — | док |
| Обложка | ≤ 4 слов (A), один центральный элемент, контраст, лицо и эмоция, A/B, 1280×720 для 16:9 (B) | A, B | обзор |
| Исследование перед записью | Trends, поиск Studio, автодополнение, «Люди также спрашивают», выдача и комментарии конкурентов | A, B, E, D | обзор |
| Метрики | CTR, удержание, AVD, поисковые запросы Studio; менять одну вещь за раз и записывать результат | A, B | обзор |
| Время и частота | Нет доказательств влияния времени загрузки (A); регулярность важнее расписания (B, D) | A, B, D | спорно |
| Нельзя | Копировать чужие описания и заголовки, набивать ключи, выдумывать таймкоды и результаты | A, E | обзор |

## 4. Что скрипты проверяют данными, а не мнением

- Главный ключ найден в подсказках поиска или в названиях топа.
- Каждый хештег (из списка, названия и описания) и тег найден в подсказках, в тегах и хештегах роликов из топа, в словах их названий или в расшифровке ролика
  (в расшифровке — и в другой форме: «сопроводительное письмо» ← «в сопроводительном письме»).
- Числа и годы в названии и описании найдены в расшифровке или в данных поиска.

## 5. Чего скрипты не делают

- Не измеряют эффект тега или хештега на показы. Берётся то, что используют ролики из топа выдачи (корреляция).
- Не знают частоту запросов: YouTube её не публикует. Ранг подсказки и число роликов с термином — косвенные признаки.
- Не оценивают качество названия и обложки: CTR и удержание видны только в YouTube Studio после публикации.
- Не ищут тренды вне YouTube (Google Trends, TikTok).
