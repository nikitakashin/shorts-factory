## Правила движка (проверено на рендере)
- Быстрый захват HyperFrames (drawElement) выключается и рендер уходит в JPEG-скриншоты — в разы медленнее и хуже —
  от: `filter: blur`, `backdrop-filter`, **`mix-blend-mode` (даже `normal`)**, **3D: `perspective`, `preserve-3d`,
  `rotateX/Y`, `matrix3d`** у контейнера с анимированными детьми, `<iframe>`, `requestAnimationFrame` во встроенном
  скрипте. Поэтому: размытие — тень текста или заранее размытая картинка; 3D — плоские приближения (скос + сжатие);
  стекло — полупрозрачные градиенты, блики, внутренняя обводка, шум. После нового блока смотри в логе
  `render_gfx.sh` строку «falling back to screenshot» — её быть не должно.
- Движение — только GSAP-твины или `drive(t => …)`; никаких CSS transition/animation.

## Темы фона (`"theme"` у панели)
| Тема | Вид | Под что |
|---|---|---|
| `dark`, `light` | синий градиент; бумага в клетку (были) | объяснения, интерфейсы |
| `noir` | почти чёрный #030303 + лёгкий центр, текст со свечением, акцент красный | кинетика, драма, «правда» |
| `black` | чистый чёрный | чёрная пауза, «не X — а Y» |
| `poster` | кремовый #FDF6EE, точечная сетка, штрихкод | журнальная подача, списки, календари |
| `blueprint` | сине-бирюзовый градиент + сетка «в полу» | дашборды, виджеты, цифры |
| `neon` | графит-зелёный, акцент #37E87C | рост, графики, «до/после» |
| `violet`, `aurora` | фиолетовые / бирюзовые пятна, медленно плавают | продукты ИИ, профили, таймлайны |
| `charcoal`, `studio`, `grid`, `void` | графит со светом; светлая студия с тенью окна; белая сетка 240; чёрный с подсветкой | смена «главы» |
Поля панели: `"ghost": "слово"` — огромное курсивное слово-фон с дрейфом; `"decor": {"kind": "cross"|"spark"|"dot", "n", "color"}` —
плавающий декор. Смена темы между панелями = смена главы (референсы чередуют крем / чёрный / цвет на ударе).

## Появление и исчезновение (поля любого блока)
`"enter"`: `rise` (по умолчанию) · `pop` (из точки 0.15→1.06→1) · `drop` (падает сверху с пружиной) · `line` (линия → пилюля →
карточка) · `blurin` (из размытия, для текста) · `slide` (+`"dir": "right"`).
`"exit"`: `implode` (замах и в точку) · `drop` · `fade`; `"exit_at"` — когда (по умолчанию за 0.24 с до конца панели).
`"layer": "over"` — блок поверх колонки по `x`/`y` (курсор); `"under"` — позади (частицы за заголовком).

Брать, когда тема ролика просит, — рецепт с таймингами в указанном разборе:

- `scan` — прожектор обходит узлы, они загораются, потом сливаются (2D_Motion); `tunnel` — шестигранный туннель;
- `feed` — сетка постов заполняется, лента прокручивается, экспоненциальный счётчик (2D_Motion_1); `click`→`done`;
- маскот `buddy` — свой нейтральный персонаж-сфера с глазами, смотрит на слово (branding_1);
- `trend` — линия падения со светящейся точкой и «перекраска мира» зелёный → красный (`tone_steps`, branding_1);
- переходы `crack` (кадр раскалывается по зубчатой линии), `spin` (поворот +20° / −38°), `wash` (заливка цветом в 3 ступени),
  `strobe` (5 миганий на «но»), `smash` (нырок ×2.3 в карточку);
- типографика: `editorial` (журнальный заголовок + гигантское серое эхо), печать с бегущей чертой, буквы вразброс,
  выделение слова плашкой за курсором, «эхо-шлейф» вместо смаза;
- монтаж (adhd-shorts): субтитры «гуляют» по кадру (`caption.layout: "wander"`), плёночный look (зерно, виньетка,
  хроматическая аберрация), финальная карточка с кодовым словом (лицо сжимается, `pip` по центру), привязка событий графики к
  долям музыки (`snap_beats`, сетка долей сверяется с бочкой ниже 120 Гц).
