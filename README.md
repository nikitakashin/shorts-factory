# ai-shorts-skills — монтаж шортсов в Claude Code

Скиллы для [Claude Code](https://claude.com/claude-code), которыми я монтирую свои шортсы и видео: снимаешь
вантейк на телефон, пишешь «смонтируй шортс» — и получаешь готовую папку к публикации. Подробно, как это
устроено, — в видео на канале **AI Native Сямыч**.

| Скилл | Что делает |
|---|---|
| [`adhd-shorts`](skills/adhd-shorts/SKILL.md) | Весь конвейер: расшифровка → монтаж «в упор» без пауз и дублей → голос → звуки → субтитры, стикеры, зумы → −14 LUFS → название, описание, хештеги, промпт обложки. Плюс черновик CapCut, чтобы править самому |
| [`just-another-youtube-seo-generator`](skills/just-another-youtube-seo-generator/SKILL.md) | SEO-упаковка по фактам: подсказки поиска YouTube + конкуренты из топа (с ключом YouTube Data API точнее, без ключа через yt-dlp, vidIQ MCP по желанию) → название, описание, хештеги, теги, закреп; валидатор режет всё, чего нет в данных или в ролике. Вызывается из `adhd-shorts` на шаге упаковки |
| [`ui-panels`](skills/ui-panels/SKILL.md) | Инфографика «под интерфейсы»: терминал, таблицы, счётчики, карточка GitHub, сетки с тумблерами — по словам из расшифровки. Сплит «графика сверху / лицо снизу» или горизонталь «графика слева / лицо справа» |

## Что умеет

- **Расшифровка локально** — Whisper large-v3-turbo через MLX на Apple Silicon, по словам, кусками (без «Продолжение следует…» на тишине).
- **Монтаж «в упор»** — дубли, оговорки, «э-э», вдохи и паузы вырезаются; края склеек выравниваются по голосу, чтобы не съедать окончания слов. Спорные склейки до рендера — картинкой (волна, слова, кадры: `cut_view.py`).
- **Голос** — Adobe Podcast Enhance (через браузер) + твоя цепочка плагинов из пресета FL Studio **без запуска FL** (`.fst` → VST3 через Spotify `pedalboard`).
- **Бриф под каждый ролик** — скилл сам решает раскладку, переходы, цвет, подачу хука и один эксперимент, сверяясь с историей прошлых роликов (`look.py`), чтобы ролики не были одинаковыми.
- **Раскладки и переходы** — лицо / сплит «графика + лицо» / графика на весь кадр / лицо в карточке поверх графики; между ними — перетекание раскладки, свайп с размытием движения, зум, глитч, круглая шторка, вспышка, засветка плёнки, расфокус, щель, ударная волна.
- **Моушн-библиотека** (`ui-panels`) — по разбору референсов: кинетическая типографика, «не X — а Y», курсор с кликом, фонтан карточек, виджеты, календарь, каскад карточек, детективная доска с нитью, карусель, неоновый график, мокап телефона, «монтажка», 13 тем фона. Свои референсы разбираются `ref_frames.py` (раскадровка по всей длине, палитра, доли).
- **Субтитры** — слова всплывают по мере речи, широкий Unbounded, свечение на акцентах, без толстой обводки; хук с первого кадра — строки разными шрифтами.
- **Картинка** — размытие фона за человеком (Apple Vision), цветокоррекция по коже и уровням кадра с образами «натурально / кино / тёплый / tech» (`grade.py`, 3D-LUT).
- **Звук** — вжухи и щелчки на склейках, мемы на акцентах, slow-mo без коррекции тона на акцентном слове, фоновая музыка на 4 дБ ниже голоса, **по долям**: сетка проверяется по бочке ниже 120 Гц, графика подтягивается к долям.
- **Проверка перед сдачей** — `qa.py` (читаемость субтитров OCR, текст на лице, зоны интерфейса Shorts, громкость звуков, пустоты) и `sound_check.py` по готовому MP4 (LUFS, моно, доли, лист «кадр до/после/волна» и 5 таймкодов для наушников — модель звук не слышит и «звучит хорошо» не пишет).
- **Горизонтальное полное видео + шортсы из него** с заставками глав и «смотри полное видео».
- **Черновик CapCut** — тот же монтаж дорожками в CapCut: двигаешь склейки, звуки, правишь субтитры и экспортируешь за полминуты.
- **Упаковка** — `youtube.md` (названия до 100 символов с хештегами, описание, теги, закреп) и промпты обложек «как кадр из фильма» по кадрам с твоим лицом.

## Требования

- **macOS на Apple Silicon** (расшифровка — MLX).
- [Claude Code](https://claude.com/claude-code).
- `ffmpeg` (`brew install ffmpeg`), [`uv`](https://docs.astral.sh/uv/) (`brew install uv`) — зависимости Python-скриптов ставятся сами.
- **Node.js 20+** — для `ui-panels` (движок [HyperFrames](https://www.npmjs.com/package/hyperframes) ставится при первом запуске).
- Размытие фона, проверка субтитров и лиц — Apple Vision через `pyobjc` (ставится сам).
- По желанию:
  - **Claude in Chrome** + аккаунт на podcast.adobe.com — для чистки голоса в Adobe Podcast Enhance;
  - свой **пресет FL Studio** (`.fst`) и установленные VST3-плагины из него — для своей цепочки на голосе;
  - **CapCut** desktop 9.x — для черновиков;
  - **ключ YouTube Data API** (`YOUTUBE_API_KEY`) — SEO-скилл точнее видит конкурентов; без него работает через `yt-dlp` (`brew install yt-dlp`).

## Настройка

### 1. Звуки (в репозитории их нет)
Скилл берёт звуки из двух библиотек, пути — в [`skills/adhd-shorts/assets/sfx_kit.json`](skills/adhd-shorts/assets/sfx_kit.json):
- `boom` — саунд-дизайн для склеек (вжухи, удары, щелчки). Я использую **BOOM ONE** от BOOM Library, разрезанный на отдельные сэмплы. Подойдёт любая библиотека — поправь пути в ролях `whoosh`, `pop`, `boom` и т.д.
- `meme` — мемные звуки для акцентов (`vineboom`, `fahh`, `bruh`…) — свои mp3; имена файлов в ролях тоже правятся в `sfx_kit.json`.

Звуки не входят в репозиторий: у библиотек свои лицензии. Без библиотек скилл синтезирует простые звуки сам.

### 2. Шрифты
Все — Google Fonts (лицензия OFL), кладутся в `~/.cache/content-factory/fonts/`:
```bash
F=~/.cache/content-factory/fonts; mkdir -p $F; G=https://github.com/google/fonts/raw/main/ofl
curl -L -o $F/Unbounded.ttf   "$G/unbounded/Unbounded%5Bwght%5D.ttf"       # субтитры, хук, стикеры
curl -L -o $F/MarckScript.ttf "$G/marckscript/MarckScript-Regular.ttf"   # рукописные акценты
curl -L -o $F/Inter.ttf       "$G/inter/Inter%5Bopsz,wght%5D.ttf"          # подписи на листах проверок
curl -L -o $F/Oswald.ttf      "$G/oswald/Oswald%5Bwght%5D.ttf"             # узкий шрифт графики
curl -L -o $F/Montserrat.ttf  "$G/montserrat/Montserrat%5Bwght%5D.ttf"     # старый вид субтитров (style: stroke)
```

### 2.5. Фоновая музыка (по желанию)
Треки — в `~/Samples/Background Music`. Темп в имени файла («… (134bpm F#min).mp3») помогает: librosa на трэпе
часто находит половинный темп, скилл сверяет его с именем и с бочкой.

### 3. Цепочка на голос из FL Studio (по желанию)
Сохрани цепочку микшера как пресет `.fst` и распакуй:
```bash
uv run --script skills/adhd-shorts/scripts/fx_chain.py extract "<пресет>.fst" ~/Movies/Shorts/_presets/video-voice
```
Скилл прогоняет через неё голос без FL. Плагины Waves грузятся долго (~4 мин) — это нормально.

### 4. Черновики CapCut (по желанию)
Формат проекта CapCut не документирован, поэтому структуру скрипт копирует с **твоего шаблона**. Сделай его один раз:
1. CapCut → новый проект 9:16.
2. Перетащи любое видео, добавь **один текст**, **один звук**, на видео поставь **два ключевых кадра масштаба** (100% → 120%).
3. Добавь **второе видео поверх** (оверлей) на любую секунду.
4. Закрой CapCut.

Имя папки шаблона (в `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/`) передавай в `--template`.
CapCut при записи черновика должен быть **закрыт**. CapCut работает в песочнице macOS и видит только `~/Movies` — скрипт сам копирует туда всё нужное.

## Как пользоваться

В Claude Code:
- «Смонтируй шортс из `~/Downloads/VID_….mp4`» — шортс + упаковка.
- «Тут 8 минут разбора — сделай полное видео и два шортса из него».
- «Добавь инфографику: таблицу с ценами на 0:15».
- «Собери черновик в CapCut».

На выходе — папка `~/Movies/Shorts/<дата>-<тема>/`:
```
short.mp4            видео 1080×1920 (или full.mp4 1920×1080), −14 LUFS
audio.wav            звук отдельно
youtube.md           названия, описание, хештеги, теги, закреп
thumbnail-prompt.md  промпт обложки по кадру с твоим лицом (с текстом заголовка)
thumb-frames/        кадры для обложки
```

## Ограничения

- Только macOS + Apple Silicon.
- Adobe Podcast — через браузерного агента; каждое скачивание файла агент подтверждает у тебя.
- Формат CapCut неофициальный: после обновления CapCut может понадобиться новый шаблон.
- Тряски, вспышек и «пунч»-зумов в черновике CapCut нет — они только в отрендеренном видео.
- Модель не слышит звук и не видит видео целиком: всё, что про звук и картинку, — замеры и листы кадров. Финальную
  проверку на слух — по 5 таймкодам из `qa/sound.md`.

## Обновление репозитория (для автора)

Скиллы правятся в рабочем проекте, сюда — копией без личных путей:
```bash
python3 tools/sync_skills.py          # rsync skills/ + замена путей (~/Samples, --template …) + проверка, что личного не осталось
```
